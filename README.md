# CourseCraft · AI课程结构引擎

一个课程设计辅助工具原型。输入学科、学段与教学目标，把模糊的教学目标拆解成可执行的能力节点结构——每个节点标注难度层级（基础/进阶/拓展）、配套教学活动、前置依赖关系，并生成可视化的能力依赖树。

[在线体验 →](https://lih633371-cloud.github.io/coursecraft/)

> 📌 当前部署的是**产品原型演示版**：下拉选择预设课程主题查看完整能力结构效果。完整版通过 Claude API 支持任意教学目标的实时拆解，架构见下方说明。

---

## 这是什么，不是什么

**这不是一套教案模板库。** 工具不提供可以直接套用的现成教案，重点是把"教学目标"这种模糊表述转化为结构化的能力图谱。

**这是把"目标拆解"这件事产品化的尝试。** 一线教师写教案时最常见的问题是教学目标写得笼统（比如"提高学生的写作能力"），却说不清楚这个目标具体拆成哪几步能力、每一步需要什么活动来落地、怎么知道学生达没达标。这个工具强制把目标拆解成 3-5 个带层级标注的能力节点，每个节点绑定一个具体活动和评价标准，让"教学设计"从经验判断变成可视化的结构决策。

## 核心功能

- **能力节点拆解**：教学目标 → 3-5 个能力节点，标注基础/进阶/拓展三级难度
- **教学活动配套**：每个节点绑定具体活动（名称、时长、互动方式、所需材料）
- **三级评价量规**：未达标/达标/优秀，明确到每个维度的具体标准
- **能力依赖树可视化**：纯 SVG 绘制，节点间的前置依赖关系一目了然，不需要额外的图表库

## 为什么是演示模式

完整版的核心能力是接入 Claude API，输入任意学科、学段、课时与教学目标后实时生成课程结构。但直接在纯前端页面里调用 API 会暴露密钥，生产环境的正确做法是加一层后端代理（比如 Cloudflare Worker）把密钥托管在服务端。

考虑到这是一个作品集展示项目而非长期运营的产品，我选择用**预生成的示例数据**替代实时调用：交互逻辑、SVG 渲染算法、视觉设计与生产版本完全一致，只是数据来源从"实时 API"换成了"内置 JSON"。

如果要恢复实时生成能力，只需要：
1. 搭建一个轻量后端代理（Worker / Serverless Function），密钥存在服务端环境变量
2. 把前端的 `DEMO_DATA` 数组替换回 `fetch()` 调用
3. `renderAbilityTree(data)` 等渲染函数无需改动，输入数据结构一致即可复用

## 特点

- **纯前端，零依赖**：不使用任何框架，一个 HTML 文件即可运行
- **纯 SVG 能力树**：不依赖 D3 或其他图表库，viewBox 自适应，响应式布局
- **完整的产品级交互**：加载动画、空状态、结果渲染均按生产标准实现

## 设计依据

能力层级（基础/进阶/拓展）与依赖关系的设计思路，来自长期做课程内容开发与教学工作中反复遇到的问题：教学目标写得再漂亮，如果不拆到"这一步需要哪个前置能力"，教案落地时就会出现学生跟不上、活动设计脱节的情况。
